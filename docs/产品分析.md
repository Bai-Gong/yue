# 百工·乐（Yue）产品分析

> 对标 Adobe Audition · 2026-10-19 留档

## 要做什么

**核心职能**：桌面级音频工作站，覆盖音频的**录制、编辑、混音与修复**，主攻播客、有声书、视频配音等后期场景。

**必备核心能力**：

- 录音与多格式导入
- 波形级编辑（剪切、裁剪、淡入淡出、标记）
- 多轨混音（轨道排布、音量/声像调节、混缩导出）
- 基础效果（EQ、压缩、混响）
- 电平监测与响度控制

**可后置高级能力**：频谱频率编辑（可视化去除特定噪声）、降噪修复套件（咔嗒声、嗡嗡声消除）、效果链保存与自动化包络、批量处理、环绕声。

## 页面呈现样式

**典型形态**：「双视图 + 多面板」工作台。

- **两大模式**：波形视图（单文件精细编辑，破坏性）与多轨视图（多片段排布混音，非破坏），一键切换、双击片段互跳
- **布局分区**：顶部菜单与工具栏、传输控制（播放/录制）；中央主编辑区（波形或轨道时间轴）；左侧文件/效果浏览器；右侧效果机架与属性参数面板；底部电平表与选区/时间读数

**交互特点**：以时间轴选区为核心范式，滚轮缩放导航，拖拽排布片段，机架式串联效果并实时试听预览。
