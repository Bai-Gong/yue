# 百工·乐（Yue）目标与里程碑

> 本文回答「做到什么、分几步、每步怎么算数」。为什么做见
> [产品分析.md](产品分析.md)。状态快照：2026-10-22（文档 + CI 阶段，
> 无业务代码）。

## 开发目标

桌面级音频工作站（对标 Audition 核心工作流）：录音、波形级编辑、
多轨混音与修复，主攻播客、有声书、视频配音等后期场景。双视图纲领
沿用产品分析：波形视图（单文件、破坏性）与多轨视图（非破坏）一键
切换。音频 IO 与 WAV/FLAC 读写用 Rust 生态库（M0 选型）；压缩格式
（AAC/MP3）读写经冶——乐是冶指定的三个消费方之一。

## 里程碑（每条以真实使用场景为准入）

- **M0 骨架**：Tauri 2 + React + 坊接入、音频 IO 选型（cpal 类）
  与 WAV 读写选型。准入：录 5 秒麦克风并回放。
- **M1 波形编辑**：打开 WAV/FLAC、波形显示（可缩放）、播放/暂停/
  选区循环、剪切/淡入淡出/标记、保存。
  准入：完成一段真实录音的粗剪（波形视图）。
- **M2 多轨混音**：多轨视图、剪辑块排列/移动/交叉淡化、音量/声像/
  独奏静音、混缩导出 WAV。准入：剪一支播客成品（人声 + 垫乐）。
- **M3 效果与响度**：EQ/压缩/混响基础效果链（可实时预听）、电平表
  与峰值/响度指示。准入：完成一集响度达标（播客平台规范）的后期。
- **M4 压缩格式与冶接入**（解锁条件：冶 M4 的 AAC 落地）：AAC/MP3
  读写经冶进程内完成、工程文件保存。
  准入：导出发布规格成品（mp3/m4a）。
- **M5+（后置池，按需触发）**：降噪修复套件、频谱频率编辑、自动化
  包络、批量处理（可与锻的队列联动）——产品分析「可后置」清单。

## 依赖与集群对齐

- 依赖坊：M0 起接入。
- 依赖冶：仅 M4 起（AAC/MP3 经冶）；此前的 ffmpeg 时代方案
  （若提前需要压缩格式）按剪/锻的 sidecar 三档定位临时过渡，
  冶 M4 落地后切换，不留双轨。
- 排期建议：M0-M3 不依赖冶，可在剪的主线之外并行启动；M4 排在
  冶 M4 之后。

## 原则

- 每个里程碑以真实使用场景为准入条件，不为了齐备而齐备。
- 音频质量优先：M0 选型必须过「录放全链路无爆音/漂移」这一关，
  再谈编辑功能。
